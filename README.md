# 🧠 Rat Mind Reading: Decoding Hippocampal Place Cells

> Reconstructing a rat's position on a linear track purely from the spiking
> activity of simulated hippocampal place cells.

![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)
![NumPy](https://img.shields.io/badge/NumPy-scientific-013243.svg)
![scikit-learn](https://img.shields.io/badge/scikit--learn-ML-F7931E.svg)

A self-contained Python pipeline that simulates a population of place cells,
characterizes what each neuron encodes, and **decodes the animal's location**
from population spiking — a compact end-to-end demonstration of modern neural
decoding.
